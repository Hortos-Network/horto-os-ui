# horto-os-ui-shared

Setup engine library: versioned `Step` modules, kits, resume, doctor, backup, status DTOs.

Used by CLI, TUI, and status-api. Not installed as a binary.

```bash
cargo test -p horto-os-ui-shared
cargo doc -p horto-os-ui-shared --no-deps
```
